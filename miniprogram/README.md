# 聆听 · 微信小程序（原生，导入即可用）

**小程序名称**：聆听　**AppID**：`wx9cb9eb6d646e8d71`　**风格**：暖秋写实

上课、开会时边录边转写，自动提取重点，生成思维导图大纲。
原生小程序，**不需要 npm、不需要构建**，微信开发者工具导入即可预览、上传。

## 一、30 秒上手

1. 微信开发者工具 → **导入项目** → 目录选这个文件夹（`miniprogram`）
2. AppID 已经填好（`wx9cb9eb6d646e8d71`），直接确认
3. 编译预览 → 进「连接设置」填后台参数（见第二节）
4. 首页「新建听课会话」→「去聆听」→ 允许麦克风 → 开始录音

> 首次调试如果还没配后台，建议在开发者工具「详情 → 本地设置」里勾上
> **不校验合法域名**，这样可以先用自建域名模式联调。

## 二、连接后台：两种方式（重点）

### 方式 A：微信云托管（推荐，个人主体也能用，**不用备案域名、不用公网**）

这条路的原理：小程序用微信私有协议直接调用你自己的容器，
**不需要在小程序后台配置任何服务器域名**，也不需要 Cloudflare 隧道那样的公网地址。

1. 打开微信云托管控制台（从微信公众平台进入，或搜「微信云托管」），
   用小程序管理员扫码开通，创建一个**环境**，记下**环境 ID**。
2. 新建**服务**，名字例如 `classroom-assistant`，
   上传容器代码：把仓库里 `deploy/modelscope-upload/` 的内容作为代码包上传
   （里面有 `Dockerfile`，会自动构建；容器监听端口填 **7860**）。
3. 等构建完成，在控制台确认服务运行中。
4. 回到小程序 →「连接设置」→ 选 **微信云托管** → 填：
   - 环境 ID：云托管控制台里的环境 ID
   - 服务名：`classroom-assistant`
5. 保存即可。实时字幕会自动走 `connectContainer`，不用再填 WebSocket 地址。

> 容器镜像怎么来的：仓库 `deploy/space/README.md` 里写了完整说明，
> 一个容器同时跑后端 API 和 FunASR 实时转写。

### 方式 B：自建域名（后端部署在别的平台时用）

在「连接设置」里选 **自建域名**，填：

- 后端地址：`https://你的域名`
- 实时字幕地址：点「按后端地址自动生成」得到 `wss://你的域名/funasr`

这种方式**必须**在微信公众平台 →「开发管理 → 开发设置 → 服务器域名」里配置：

| 类型 | 需要填写 |
| --- | --- |
| request 合法域名 | `https://你的域名` |
| uploadFile 合法域名 | `https://你的域名` |
| socket 合法域名 | `wss://你的域名` |

域名要求：HTTPS/WSS、**已 ICP 备案**、不能是 IP。

## 三、功能一览

| 功能 | 说明 |
| --- | --- |
| 会话列表 / 新建会话 | 首页，标题、状态、时长一目了然 |

| 网页版入口 | 企业主体可用 `<web-view>` 打开 H5 |

## 五、上线前必须做的三件事

1. **用户隐私保护指引**：声明「麦克风」「录音」「录音上传到服务器」，否则录音接口会被平台拦截。
2. **服务类目**：选 **工具 → 办公**（个人主体即可，无需额外资质）；不要选教育类目。
3. **域名**：用云托管不用配；用自建域名必须配 request / uploadFile / socket 三类合法域名。

## 六、需要真机验证的 5 件事

这份代码在写的时候**没有微信开发者工具可用**，所以以下要在真机上确认：

1. `wx.getRecorderManager()` 用 `format: "PCM"` + `frameSize` 在你手机上能否正常出帧。
2. 实时字幕延迟（现在每帧约 192ms，太卡可以调大 `FRAME_SIZE_KB`）。
3. 9.5 分钟自动续录，前后两段的拼接有没有明显断点。
4. 切后台 / 来电打断后能否恢复（官方：切后台 5 秒后 JS 线程挂起）。
5. 云托管模式下 `connectContainer` 的 WebSocket 是否稳定（基础库需 ≥ 2.23.0）。

遇到报错把提示发我，我直接改代码。
